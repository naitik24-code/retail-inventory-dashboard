Machine Learning Models

Detailed explanation of models and methodologies

1. Data Preparation

  • Loaded 3,732 SKUs from Zepto dataset
  • 12 months of consumption data analyzed
  • Feature engineering: Annual Consumption, CV, Mean Demand
  • StandardScaler applied for normalization

2. Feature Engineering

  • Annual Consumption: Sum of 12 monthly values
  • Mean Demand: Average monthly demand
  • CV (Coefficient of Variation): std_dev / mean
  • Available Quantity: Current stock levels
  • Price Metrics: MRP and discounted prices

3. Classification Strategy

ABC Analysis: Based on Annual Value (consumption × price)

  • Class A: Top 70% cumulative value
  • Class B: Next 20% cumulative value
  • Class C: Remaining 10% cumulative value

XYZ Analysis: Based on Coefficient of Variation

  • Class X: CV ≤ 0.5 (High predictability)
  • Class Y: 0.5 < CV ≤ 1.0 (Medium predictability)
  • Class Z: CV > 1.0 (Low predictability)

4. Model Training

Supervised Models:

  • Random Forest: 100 estimators, trained on 19 features
  • XGBoost: Gradient boosting with learning rate 0.1

Unsupervised Models:

  • K-Means & GMM: 9 components for ABC/XYZ
  • DBSCAN: eps=0.5, min_samples=10 for outliers

Sample Code: DBSCAN Implementation

import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import DBSCAN
from sklearn.decomposition import PCA

# Load and prepare data
df = pd.read_csv('Project IMS.csv')
high_impact_cols = [
    'availableQuantity', 'Annual_Consumption',
    'outOfStock', 'mrp', 'discountedSellingPrice'
]
X = df[high_impact_cols].copy()

# Scale features
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# Apply DBSCAN
dbscan = DBSCAN(eps=0.5, min_samples=10)
dbscan_labels = dbscan.fit_predict(X_scaled)

# PCA for visualization
pca = PCA(n_components=2)
principal_components = pca.fit_transform(X_scaled)

About This Research

This project represents a comprehensive study on Smart Inventory Management Systems for retail businesses. Developed as part of research at the Department of AITCSE, Chandigarh University, Punjab, India.

The system provides real-time inventory tracking, dead stock detection, and actionable insights for inventory optimization. The platform helps retail shop owners make data-driven decisions to improve stock management and reduce capital locked in slow-moving or dead stock items.
